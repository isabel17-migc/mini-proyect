PRÁCTICA DE POSICIONES EN CSS

Esta práctica consiste en aprender a utilizar la propiedad position de CSS para controlar la ubicación de los elementos dentro de una página web.

¿Qué es la propiedad position?

Es una propiedad de CSS que permite establecer cómo se posicionan los elementos en una página web.

1. Posición static

Es la posición predeterminada. Los elementos aparecen siguiendo el orden normal de la página.

Ejemplo de posición static.

2. Posición relative

Permite desplazar un elemento desde su posición original utilizando las propiedades top, right, bottom y left.

Ejemplo de posición relative.

3. Posición absolute

Permite colocar un elemento en una posición específica respecto a su contenedor posicionado.

Ejemplo de posición absolute.

4. Posición fixed

Mantiene un elemento fijo respecto a la ventana del navegador, incluso cuando se desplaza la página.

Ejemplo de posición fixed.

5. Posición sticky

Permite que un elemento se comporte normalmente y después permanezca adherido a una posición al desplazarse por su contenedor.

Ejemplo de posición sticky.

Propiedades complementarias

  • top: establece la distancia desde arriba.
  • right: establece la distancia desde la derecha.
  • bottom: establece la distancia desde abajo.
  • left: establece la distancia desde la izquierda.
  • z-index: controla qué elemento aparece delante de otro.

Conclusión

La propiedad position de CSS es importante para organizar los elementos de una página web y controlar su ubicación. Sus valores static, relative, absolute, fixed y sticky permiten crear diferentes diseños.

¿Qué aprendimos?

Aprendimos que CSS permite controlar la posición de los elementos mediante la propiedad position.

Recuerda

HTML organiza el contenido de una página y CSS permite modificar su apariencia y posicionamiento.
